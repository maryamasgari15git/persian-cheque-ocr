# Persian Cheque OCR

استخراج خودکار اطلاعات از چک‌های صیادی ایرانی با استفاده از OCR، به‌صورت کاملاً آفلاین.

## هدف پروژه

پردازش تصویر چک‌های دست‌نویس فارسی (چک صیادی) و استخراج ساختاریافته‌ی فیلدهای کلیدی
(تاریخ، مبلغ به عدد، مبلغ به حروف، شماره صیادی، شماره حساب/شبا، نام گیرنده، امضا)
بدون نیاز به اتصال اینترنت یا سرویس‌های ابری.

## معماری کلی

چون چیدمان چک‌های صیادی در همه‌ی بانک‌ها استاندارد و یکسان است، معماری پروژه به این
صورت طراحی شده:

1. **Alignment** — تشخیص ۴ گوشه‌ی چک با مدل [DocAligner](https://github.com/DocsaidLab/DocAligner)
   و صاف‌سازی تصویر (اصلاح چرخش و پرسپکتیو) به یک template ثابت (1200×600).
2. **Field Extraction** — جدا کردن هر فیلد بر اساس مختصات ثابت (تعریف‌شده در
   `configs/fields.yaml`)، چون بعد از align شدن، جای فیلدها روی همه‌ی چک‌ها یکسان است.
3. **OCR تخصصی هر فیلد** (مرحله‌ی بعدی، هنوز شروع نشده) — فیلدهای رقمی و متنی هرکدام
   با مدل مناسب خودشان پردازش خواهند شد.
4. **اعتبارسنجی متقابل** (مرحله‌ی بعدی) — مقایسه‌ی مبلغ عددی و مبلغ حرفی برای تشخیص خطا.

## وضعیت فعلی پروژه

- ✅ تشخیص گوشه و صاف‌سازی تصویر چک (DocAligner)
- ✅ ابزار دستی انتخاب مختصات فیلدها (`scripts/field_selector.py`)
- ✅ Crop خودکار فیلدها بر اساس مختصات ذخیره‌شده
- ✅ رابط وب ساده (FastAPI) برای آپلود یک چک جدید و مشاهده‌ی نتیجه‌ی صاف‌سازی و جداسازی فیلدها
- 🔜 OCR روی فیلدهای رقمی
- 🔜 OCR روی فیلدهای متنی آزاد (نام، مبلغ به حروف)
- 🔜 اعتبارسنجی متقابل مبلغ عددی/حرفی
- 🔜 خروجی نهایی ساختاریافته (JSON) + فلگ موارد کم‌اطمینان برای بازبینی دستی

## ساختار پروژه
persian-cheque-ocr/
├── app.py # اپلیکیشن وب FastAPI برای تست
├── configs/

├── scripts/

## نصب و اجرا

```bash
python -m venv venv
venv\Scripts\activate          # ویندوز
pip install -r requirements.txt
```

**وابستگی خارجی مهم (نصب دستی، خارج از pip):**
- [libjpeg-turbo](https://github.com/libjpeg-turbo/libjpeg-turbo/releases) نسخه‌ی
  ویندوزی (`vc-x64`) — پیش‌نیاز کتابخانه‌ی `docaligner`. باید در مسیر پیش‌فرض
  `C:\libjpeg-turbo64` نصب شود.

**اجرای رابط وب:**
```bash
uvicorn app:app --reload
```
سپس مرورگر را روی `http://127.0.0.1:8000` باز کنید، یک عکس چک آپلود کنید و نتیجه‌ی
صاف‌سازی + جداسازی فیلدها را ببینید.

## تنظیم مجدد مختصات فیلدها (در صورت نیاز)

اگر چیدمان یک چک با template فعلی فرق داشت یا خواستید فیلد جدیدی اضافه کنید:
```bash
python scripts/field_selector.py
```
با ماوس دور هر فیلد مستطیل بکشید، اسمش را وارد کنید، در پایان `s` را برای ذخیره در
`configs/fields.yaml` بزنید.
